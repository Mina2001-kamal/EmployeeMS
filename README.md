# Employee Management System

Full Stack Project using:

- ASP.NET Core Web API
- SQL Server
- HTML, CSS, JavaScript
- Fetch API

## Features

- Add Employee
- View Employees
- Update Employee
- Delete Employee
- Search Employee
- Full Validation (Frontend + Backend)

## How to Run

### Backend

- Open in Visual Studio
- Update connection string
- Run API

### Frontend

- Open index.html using Live Server
